# 我的个人网站 | My Personal Website

这是一个简单而优雅的个人网站，使用纯HTML、CSS和JavaScript构建。

This is a simple and elegant personal website built with pure HTML, CSS, and JavaScript.

## 特性 | Features

- 📱 响应式设计，适配各种设备 | Responsive design for all devices
- 🎨 现代化的界面设计 | Modern UI design
- ⚡ 快速加载，无需构建工具 | Fast loading, no build tools needed
- 🌐 中英双语支持 | Bilingual support (Chinese & English)
- 🎭 流畅的动画效果 | Smooth animations

## 快速开始 | Quick Start

1. 克隆仓库 | Clone the repository:
```bash
git clone https://github.com/lonlyers/my-site.git
cd my-site
```

2. 打开网站 | Open the website:
   - 方法1：直接在浏览器中打开 `index.html` 文件
   - 方法1: Open `index.html` directly in your browser
   - 方法2：使用本地服务器（推荐）
   - 方法2: Use a local server (recommended)

使用Python启动本地服务器 | Start a local server with Python:
```bash
# Python 3
python -m http.server 8000

# 或者使用 Python 2
python -m SimpleHTTPServer 8000
```

然后在浏览器中访问 `http://localhost:8000`

Then visit `http://localhost:8000` in your browser

## 自定义 | Customization

### 修改个人信息 | Update Personal Information

编辑 `index.html` 文件中的以下部分：
Edit the following sections in `index.html`:

- 导航栏标题 | Navigation title
- 关于我部分 | About section
- 项目展示 | Projects showcase
- 联系方式 | Contact information

### 修改样式 | Update Styles

编辑 `styles.css` 文件中的CSS变量来快速更改颜色主题：
Edit the CSS variables in `styles.css` to quickly change the color theme:

```css
:root {
    --primary-color: #2c3e50;
    --secondary-color: #3498db;
    --accent-color: #e74c3c;
    --text-color: #333;
    --light-bg: #f8f9fa;
    --white: #ffffff;
}
```
