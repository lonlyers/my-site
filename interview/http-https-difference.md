# HTTP 与 HTTPS 的区别

## 1. 基本概念

- **HTTP** (HyperText Transfer Protocol)：超文本传输协议，是互联网上应用最为广泛的一种网络协议，是一个客户端和服务器端请求和应答的标准（TCP），用于从 WWW 服务器传输超文本到本地浏览器的传输协议。
- **HTTPS** (HyperText Transfer Protocol Secure)：是以安全为目标的 HTTP 通道，简单讲是 HTTP 的安全版，即 HTTP 下加入 SSL 层，HTTPS 的安全基础是 SSL，因此加密的详细内容就需要 SSL。

## 2. 主要区别

| 特性 | HTTP | HTTPS |
| :--- | :--- | :--- |
| **安全性** | 明文传输，不安全 | 经过 SSL/TLS 加密，安全 |
| **端口** | 80 | 443 |
| **证书** | 不需要 | 需要申请 CA 证书，通常需要付费 |
| **连接方式** | 无状态连接 | SSL+HTTP 协议构建的可进行加密传输、身份认证的网络协议 |
| **SEO** | 百度、谷歌等搜索引擎会优先收录 HTTPS 网页 | 更有利于 SEO |

## 3. HTTPS 工作原理简述
1. 客户端发起 HTTPS 请求。
2. 服务端发送证书（包含公钥）。
3. 客户端验证证书合法性。
4. 客户端生成随机对称密钥，用公钥加密发送给服务端。
5. 服务端用私钥解密得到对称密钥。
6. 双方使用对称密钥进行加密通信。
